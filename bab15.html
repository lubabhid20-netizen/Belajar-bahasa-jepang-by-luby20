Tata Bahasa (ぶんぽう)

1. Kata Kerja Bentuk て も いいですか (Boleh...?)

Pola kalimat ini digunakan untuk meminta izin melakukan sesuatu kepada lawan bicara.

  • Contoh Pertanyaan:
    写真しゃしん を 撮とって も いい です か。
    👉 Boleh mengambil foto?

  • Contoh Jawaban (Mengizinkan):
    ……ええ、[撮とっても] いい です よ。
    👉 ……Ya, boleh [mengambil].

  • Contoh Jawaban (Menolak / Alasan):
    ……すみません、ちょっと……。喉のど が 痛いたい です から。
    👉 ……Maaf, agak ... karena kerongkongan saya sakit.
2. Kata Kerja Bentuk て は いけません (Tidak boleh...)

Pola kalimat ini menyatakan larangan untuk melakukan suatu perbuatan.

  • Contoh:
    ここで たばこ を 吸すって は いけません。禁煙きんえん です から。
    👉 Tidak boleh merokok di sini. Sebab dilarang merokok (*kin'en desu kara*).
3. Kata Kerja Bentuk て います (Menyatakan Keadaan, Status, & Kebiasaan)

Selain menyatakan kegiatan yang sedang berlangsung, pola ~te imasu juga digunakan untuk menyatakan keadaan status, kebiasaan, atau pekerjaan tetap.

  • Contoh 1 (Status / Keadaan):
    わたし は 結婚けっこんして います。
    👉 Saya telah menikah.

  • Contoh 2 (Mengenal / Tahu):
    わたし は 田中たなかさん を 知しって います。
    👉 Saya kenal Sdr. Tanaka. *(Bentuk negatifnya: 知しりません / shirimasen)*

  • Contoh 3 (Kepemilikan):
    わたし は カメラ を 持もっています。
    👉 Saya mempunyai kamera.

  • Contoh 4 (Tempat Tinggal):
    わたし は 大阪おおさか に 住すんで います。
    👉 Saya tinggal di Osaka.

  • Contoh 5 (Pekerjaan / Produksi Berulang):
    IMC は コンピューターソフト を 作つくって います。
    👉 IMC memproduksi perangkat lunak komputer.
4. Kata Benda に Kata Kerja (Titik Tempat Aksi / Hasil Aksi)

Partikel に (ni) digunakan bersama kata kerja tertentu (seperti masuk, duduk, naik) untuk menunjukkan tempat tujuan/sasaran dari aksi tersebut.

  • Contoh:
    ここ に 入はいって は いけません。
    👉 Tidak boleh masuk ke sini.

  • Contoh 2:
    ここ に 座すわって も いい です か。
    👉 Boleh duduk di sini?
5. Kata Benda₁ に Kata Benda₂ を Kata Kerja (Meletakkan di Tempat)

Partikel に (ni) menunjukkan lokasi tempat suatu benda (*Kata Benda₂*) diletakkan atau ditempatkan (*Kata Benda₁*).

  • Contoh 1:
    ここ に 車くるま を 止とめて ください。
    👉 Hentikan mobil di sini.

  • Contoh 2:
    ここ に 住所じゅうしょ を 書かいて ください。
    👉 Tuliskan alamat di sini.
