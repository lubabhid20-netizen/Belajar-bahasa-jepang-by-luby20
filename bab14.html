文ぶん法ぽう (Tata Bahasa)

1. 動詞どうしのグループ (Kelompok Kata Kerja)

Kata kerja bahasa Jepang dibagi menjadi 3 kelompok utama berdasarkan bentuk konjugasinya:

Kelompok Ciri-ciri & Penjelasan Contoh
第だい1グループ
(Kelompok I / Godan Doushi)		 Berakhiran bunyi di kolom い (i) sebelum 言います (言います). 書かきます (kakimasu), 飲のみます (nomimasu)
第だい2グループ
(Kelompok II / Ichidan Doushi)		 Sebagian besar berakhiran bunyi di kolom え (e) sebelum 言います. 食たべます (tabemasu), 見みます (mimasu)
第だい3グループ
(Kelompok III / Fukusoku Doushi)		 Terdiri dari kata kerja 来きます (kimasu), します (shimasu), dan gabungan kata benda + します. 来きます (kimasu), 散歩さんぽします (sanpo shimasu)
2. 動詞どうしのて形けい (Kata Kerja Bentuk TE)

Bentuk konjugasi yang sangat penting untuk menghubungkan kalimat, membuat perintah, dan menyatakan kegiatan sedang berlangsung.

  • Kelompok I (Perubahan khusus):
    - ~い / ~ち / ~り ➔ ~って (Contoh: 買かいます ➔ 買かって)
    - ~み / ~び / ~に ➔ ~んで (Contoh: 飲のみます ➔ 飲のんで)
    - ~き / ~ぎ ➔ ~いて / ~いで (Contoh: 書かきます ➔ 書かいて / 急いそぎます ➔ 急いそいで ※行いきます menjadi 行いって)
    - ~し ➔ ~して (Contoh: 話はなします ➔ 話はなして)

  • Kelompok II: Akhiran ます dihilangkan lalu ditambah て.
    (Contoh: 食たべます ➔ 食たべて / 見みます ➔ 見みて)

  • Kelompok III:
    - 来きます ➔ 来きて
    - します / Kata Benda + します ➔ して / Kata Benda + して
3. Kata Kerja [Bentuk て] ください (Tolong...)

Digunakan untuk meminta atau memerintahkan lawan bicara melakukan sesuatu dengan sopan.

  • Contoh 1 (Permintaan sopan):
    すみませんが、この 漢字かんじ の 読よみ方かた を 教おしえて ください。
    👉 Permisi, tolong ajarkan cara membaca Kanji ini.

  • Contoh 2 (Perintah/Petunjuk):
    ボールペン で 名前なまえ を 書かいて ください。
    👉 Tolong tuliskan nama dengan bolpoin.
4. Kata Kerja [Bentuk て] います (Sedang Melakukan Sesuatu)

Pola ini menunjukkan bahwa suatu aksi/kegiatan sedang berlangsung saat ini (*sedang...*).

  • Contoh 1:
    ミラーさん は 今いま 電話でんわ を かけて います。
    👉 Sdr. Miller sedang menelepon.

  • Contoh 2 (Pertanyaan & Jawaban):
    今いま 雨あめ が 降ふって います か。
    👉 Apakah sekarang sedang turun hujan?
    ……はい、降ふって います。
    👉 ……Ya, sedang turun hujan.
    ……いいえ、降ふって いません。
    👉 ……Tidak, tidak sedang turun hujan.
5. Kata Kerja [Bentuk ます] ましょうか (Bagaimana kalau saya...?)

Digunakan saat pembicara menawarkan bantuan atau usulkan untuk melakukan sesuatu bagi lawan bicara.

  • Contoh 1:
    傘かさ を 貸かしましょう か。
    👉 Bagaimana kalau saya pinjamkan payung?
    ……すみません、願ねがいします。
    👉 ……Terima kasih, tolong pinjamkan.

  • Contoh 2:
    荷物にもつ を 持もしましょう か。
    👉 Bagaimana kalau saya membawakan barang?
    ……いいえ、けっこうです。
    👉 ……Tidak, terima kasih.
6. Kata Benda が Kata Kerja (Kejadian Alam / Objektif)

Partikel が (ga) dipakai untuk subjek saat menyatakan fenomena alam atau melaporkan kejadian yang ditangkap oleh panca indera secara objektif.

  • Contoh:
    雨あめ が 降ふって います。
    👉 Hujan turun.
