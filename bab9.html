Tata Bahasa (ぶんぽう)

1. Kata Benda が あります / わかります / 好きです / 嫌いです / 上手です / 下手です

Sebagian Kata Kerja (*arimasu, wakarimasu*) dan Kata Sifat/Adjektival (*suki, kirai, jouzu, heta*) menggunakan partikel が (ga) untuk menandai objek yang menjadi sasaran kemampuan, kepemilikan, atau perasaan.

  • Kepemilikan (Benda Mati): Kata Benda + が あります
    Contoh: わたし は 車くるま が あります。
    👉 Saya mempunyai mobil.

  • Kemampuan / Pemahaman: Kata Benda + が わかります
    Contoh: わたし は 日本語にほんご が わかります。
    👉 Saya mengerti bahasa Jepang.

  • Perasaan / Kesukaan: Kata Benda + が 好きです / 嫌いです
    Contoh: わたし は イタリア料理りょうり が 好すきです。
    👉 Saya suka masakan Italia.

  • Kecakapan / Keahlian (Pandai - 上手): Kata Benda + が 上手です
    Contoh: ミラーさん は え が 上手じょうず です。
    👉 Sdr. Miller pandai melukis/menggambar.

  • Kecakapan / Keahlian (Tidak Pandai - 下手): Kata Benda + が 下手です
    Contoh: わたし は テニス が 下手へた です。
    👉 Saya tidak pandai bermain tenis.
2. どんな Kata Benda

Kata tanya どんな (donna) digunakan untuk menanyakan jenis, ragam, atau rincian spesifik dari suatu kata benda.

  • Contoh Pertanyaan & Jawaban:
    どんな スポーツ が 好すきですか。
    👉 Suka olahraga apa?
    ……サッカー が 好すきです。
    👉 ……Suka sepak bola.
3. Kata Keterangan Tingkat & Kuantitas (よく / だいたい / たくさん / 少し / あまり / 全然)

Kata keterangan diletakkan tepat di depan kata kerja atau kata sifat yang diterangkannya untuk menyatakan tingkat frekuensi atau jumlah.

  • Digunakan pada Kalimat Positif:
    • 英語えいご が よく わかります。 (Mengerti bahasa Inggris dengan baik).
    • お金かね が たくさん あります。 (Uang ada banyak).

  • Digunakan pada Kalimat Negatif (Diikuti bentuk negatif):
    • 英語えいご が あまり わかりますせん。 (Tidak begitu mengerti bahasa Inggris).
    • お金かね が 全然 ありませんせん。 (Uang tidak ada sama sekali).
4. ~ から (Menyatakan Alasan / Sebab)

Partikel から (kara) diletakkan di akhir kalimat alasan untuk menjelaskan latar belakang atau alasan dari pernyataan di kalimat utama berikutnya.

  • Contoh 1 (Alasan di depan):
    時間じかん が ありません から、新聞しんぶん を 読よみません。
    👉 Karena tidak ada waktu, tidak membaca surat kabar.

  • Contoh 2 (Jawaban atas pertanyaan alasan):
    毎朝新聞を読みますか。
    👉 Apakah membaca surat kabar setiap pagi?
    ……いいえ、読よみません。時間じかん が ありません から。
    👉 ……Tidak, tidak membaca. Karena tidak ada waktu.
5. どうして (Kenapa / Mengapa)

どうして (doushite) adalah kata tanya yang digunakan untuk menanyakan alasan. Jawabannya wajib diakhiri dengan partikel から.

  • Contoh Pertanyaan & Jawaban:
    どうして 朝あさ 新聞しんぶん を 読よみません か。
    👉 Mengapa pada pagi hari tidak membaca surat kabar?
    ……時間じかん が ありません から。
    👉 ……Sebab tidak ada waktu.
