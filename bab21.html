Tata Bahasa (ぶんぽう)

1. [Bentuk Biasa] と 思おもいます (Saya kira... / Saya pikir...)

Digunakan untuk menyatakan pendapat, pikiran, atau dugaan pribadi pembicara. Partikel と menandai isi pikiran tersebut.

  • ① あした 雨あめが 降ふると 思おもいます.
    👉 Saya kira besok hujan turun.
  • ② テレーザちゃんは もう 寝ねたと 思おもいます.
    👉 Saya kira Teresa sudah tidur. *(Catatan: Jika isi dugaan negatif, bentuk negatif diletakkan di depan と, misal: 知らない と 思います / saya kira tidak tahu)*.
  • ④ 日本にほんは 物価ぶっかが 高たかいと 思おもいます.
    👉 Saya pikir Jepang harga barangnya mahal.
  • ⑤ 新あらしい 空港くうこうについて どう 思おもいますか.
    👉 Mengenai bandara baru, menurut Anda bagaimana?
2. ["Kalimat" Bentuk Biasa] と 言いいます (Mengatakan bahwa...)

Digunakan untuk mengutip atau menyampaikan kembali ucapan seseorang.

  • ⑦ 寝ねる まえに、「お休やすみなさい」と 言いいます.
    👉 Sebelum tidur mengucapkan “Selamat tidur”.
  • ⑨ ミラーさんは 東京とうきょうへ 出張しゅっちょうすると 言いいました.
    👉 Sdr. Miller mengatakan bahwa dinas ke Tokyo.
  • ⑩ 父ちちに 留学りゅうがくしたいと 言いいました.
    👉 Saya berkata kepada ayah bahwa ingin belajar di luar negeri.
3. [Bentuk Biasa] でしょう？ (..., bukan?)

Digunakan saat bertanya untuk meminta persetujuan dari lawan bicara atau menegaskan sesuatu dengan nada naik.

  • ⑪ あした パーティーに 行いくでしょう？ / ……ええ、行いきます.
    👉 Besok pergi ke pesta, bukan? / ……Ya, pergi.
  • ⑫ 北海道ほっかいどうは 寒さむかったでしょう？ / ……いいえ、そんなに 寒さむくなかったです.
    👉 Hokkaido dingin, bukan? / ……Tidak, tidak begitu dingin.
4. Kata Benda (tempat) で Kata Benda (acara) が あります

Partikel で digunakan untuk menyatakan tempat diadakannya suatu acara, pesta, atau perayaan.

  • ⑬ 東京とうきょうで 日本にほんと ブラジルの サッカーの 試合しあいが あります.
    👉 Di Tokyo diadakan pertandingan sepak bola antara Jepang dan Brasil.
5. Kata Benda (adegan) で / Kata Benda でも Kata Kerja
  • ~で: Menyatakan adegan/situasi saat suatu aksi dilakukan (misal: 会議で / di dalam rapat).
  • ~でも: Digunakan saat menawarkan atau mengusulkan sesuatu dengan menyebutkan satu contoh dari beberapa kemungkinan (misal: ちょっと ビールでも 飲のみませんか / Bagaimana kalau minum bir, atau...?).
